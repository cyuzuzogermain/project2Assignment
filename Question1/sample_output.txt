  --- How to read the Academic Risk Index ---
  Purpose : an early-warning score showing how far a grade sits below
            a safe level, so a 58 and a 20 are not treated as equally
            at risk: the further below the threshold, the higher the
            score.
  Formula : risk = 0                                     if grade >= threshold
            risk = (threshold - grade) / threshold * 100   otherwise
  Worked example (default threshold 60):
              grade 55 -> (60-55)/60*100 =  8.3
              grade 45 -> (60-45)/60*100 = 25.0
              grade 30 -> (60-30)/60*100 = 50.0
              grade  0 -> (60- 0)/60*100 = 100.0
  Bands   : 0 = Safe; above 0 up to 25 = Low risk; above 25 up to 50 =
            Moderate risk; above 50 = High risk.
  Reading : 0 means the student is at or above the safe level.  The
            higher the index the further below it; 100 means a grade
            of 0.  Only students above 0 are listed as at risk.
  Current threshold in use: 60, so the same formula gives, for example,
              grade 30.0 (half the threshold) -> 50.0   and   grade 0 -> 100.0
  Note    : the pass mark (50) is a separate scale used by the summary
            report; this analysis always uses the threshold shown here.
